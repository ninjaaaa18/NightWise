# NightWise

### Navigate Smarter. Travel Safer.

NightWise is an AI-powered, safety-aware navigation platform designed to help women make more informed travel decisions using geospatial intelligence, infrastructure indicators, community observations and route analysis.

## Vision

Make urban navigation more informed and transparent by helping users compare routes using available environmental and infrastructure evidence.

## Initial Coverage
Bengaluru, Karnataka, India.

## Platforms
- Web Application
- Android Application

## Technology Stack

| Layer | Technology |
|---|---|
| Web | React, TypeScript, Vite |
| Android | React Native, Expo |
| Backend | Python, FastAPI |
| Database | Supabase, PostgreSQL, PostGIS |
| Authentication | Supabase Auth |
| Maps | MapLibre, OpenStreetMap |
| Routing | OSRM |
| Data Processing | Pandas, NumPy, GeoPandas |
| Machine Learning | Scikit-learn |
| AI Explanations | LLM API |

## Core Features
- Safety-aware route comparison
- Geospatial safety indicators
- Infrastructure intelligence
- Community reporting
- AI-powered route explanations
- Administrative moderation

## Important Disclaimer

NightWise provides indicative information based on available data. It does not guarantee personal safety, predict crime or replace individual judgement or emergency services.
